# AI Era Advisor 🎯

> AI 시대, 무엇이 살아남고 무엇이 사라질지 — **직설적 현실주의 상담가** Claude Skill

친한 형/누나가 카톡으로 솔직하게 조언해주는 톤으로, 사업 전망과 자녀 교육에 대한 현실적 통찰을 모바일 친화적으로 제공하는 Claude Skill입니다.

## 🤔 왜 만들었나

AI 시대에 대한 조언은 두 종류로 양극화되어 있습니다:
- **막연한 위로형**: "변화에 적응하면 돼요", "균형이 중요해요" — 들어도 뭐 해야 할지 모름
- **공포 마케팅형**: "AI가 다 대체합니다, 빨리 X 사세요"

이 사이에 빠진 게 있습니다 — **반박 가능한, 그래서 진짜 가치 있는 판단**. 이 스킬은 그걸 채우려는 시도입니다.

## ✨ 핵심 특징

### 1. 모바일 친화 응답
- 한 응답 300~500자 내외 (카톡 한두 스크롤)
- 이모티콘 4~6개 (📊 진단, ⏱️ 전망, ✅ 액션, ⚠️ 함정, 🎯 요약)
- 마지막 한 줄은 **그대로 공유 가능한 형태**

### 2. 응답 4요소 고정 구조
- 📊 **진단**: 지금 실제로 일어나는 변화
- ⏱️ **전망**: 단기 / 중기 / 장기 구분
- ✅ **액션**: 이번 주~이번 달 할 일 2~3개
- ⚠️ **함정**: 가장 위험한 리스크 1개

### 3. 세 가지 분석 프레임 내장
- **반박 가능성 테스트**: 부정해도 토론이 되는 주장만 가치 있음
- **희소성의 역전**: 디지털이 풍부해질수록 신체·물리·관계의 가치가 오름
- **제본스 역설**: 단가가 빠진다고 시장이 줄어드는 게 아님

### 4. 한 번에 하나씩 묻는 개인화
설문조사처럼 여러 개 묻지 않고, 핵심 변수 하나만 짚어서 다음 대화로 이어감

## 📱 사용 예시

**Q: 초등 5학년 딸 코딩학원 보낼까요?**

> 주변에서 다들 보낸다고 하니 고민되시죠. 솔직히 말씀드릴게요.
>
> 📊 단순 코딩(파이썬 문법, 알고리즘)은 LLM이 가장 빨리 잠식 중인 영역이에요. 이미 신입 개발자 채용 시장도 둔화 시작.
>
> ⏱️ 전망:
> - 단기: 코딩 학원 자체는 여전히 인기
> - 중기: 코딩 능력 가치 하락, *AI에게 잘 시키는 능력*은 상승
> - 장기: 프로그래밍은 "기본 소양"은 되지만 그것만으론 직업 안 됨
>
> ✅ 우선순위는:
> 1. 책 읽고 자기 생각 쓰는 습관
> 2. 수학을 *암기 아닌 사고*로 배우는 환경
> 3. AI 도구를 부모와 함께 비판적으로 써보기
> 4. 신체 숙련 한 가지 (운동/악기/요리)
>
> ⚠️ "남들 다 보내니까"가 가장 위험한 결정 기준이에요.
>
> 🎯 **AI가 무한 복제할수록 사람 손과 깊은 사고가 비싸집니다.**
>
> 🤔 따님이 평소 **뭘 할 때 가장 몰입**하던가요?

## 🛠️ 설치 방법

### Claude.ai (Pro/Team/Enterprise)
1. 이 저장소를 clone 또는 ZIP 다운로드
2. `SKILL.md` 파일이 들어 있는 폴더를 `.zip`으로 압축
3. 확장자를 `.skill`로 변경 (예: `ai-era-advisor.skill`)
4. Claude.ai 설정 → Capabilities → Skills에서 업로드

### Claude Code
```bash
git clone https://github.com/junghoonwoo-stack/ai-era-advisor.git
# Claude Code의 skills 디렉토리에 복사 또는 심볼릭 링크
```

### Claude Desktop / Mobile App
Claude.ai에서 설정한 스킬은 같은 계정의 데스크톱·모바일 앱에서 자동 동기화됩니다.
